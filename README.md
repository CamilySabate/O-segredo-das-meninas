# Segredo das Meninas

Bem-vindos ao **Segredo das Meninas!**

Este repositório reúne um projeto desenvolvido em grupo, no qual cada integrante terá sua própria página pessoal, criada utilizando **HTML e CSS**.

A proposta é desenvolver páginas individuais que representem a personalidade, os gostos, os interesses e a criatividade de cada integrante, explorando conceitos de desenvolvimento web e design.

## Objetivo do projeto

Criar páginas pessoais individuais, colocando em prática conhecimentos de HTML e CSS, trabalhando conceitos como estruturação, estilização, identidade visual e responsividade.

## Desenvolvimento

Cada integrante será responsável pelo desenvolvimento da sua própria página, explorando diferentes estilos, layouts e elementos visuais.

O projeto também permite praticar organização de arquivos, versionamento de código e colaboração por meio do Git e GitHub.
